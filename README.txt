# Janani R S — Portfolio Website

A responsive, interactive personal portfolio built with HTML, CSS, and JavaScript.

## Run locally
1. Extract the ZIP file.
2. Keep `index.html` and the `assets` folder together.
3. Open `index.html` in a modern browser.

No build tools or package installation are required.

## Publish online
You can deploy this folder with GitHub Pages, Netlify, or Vercel. For GitHub Pages, create a repository, upload `index.html` and the `assets` folder, then enable Pages in the repository settings.
