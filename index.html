Smart Vision

Condition-Aware Object Detection

An AI-powered computer vision project exploring environmental condition classification and object detection under challenging visibility conditions.

  • Classifies six conditions: Normal, Low-Light, Fog, Rain, Snow, and Sand/Dust.
  • Audited, cleaned, and balanced a 1,200-image dataset using selected images from ExDark, DAWN, and VOC2007/2012.
  • Uses EfficientNet for condition classification, with YOLO-based object detection under exploration.
